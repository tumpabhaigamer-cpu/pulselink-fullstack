# PulseLink Full-Stack

Next.js application source extracted from the supplied Linktree system architecture ZIP.

## Run locally

```sh
npm install
npm run dev
```

Configure the database and any provider integrations in your deployment environment before using the server routes. Never commit `.env` files or production credentials.

This repository hosts the source code. GitHub Pages cannot run this app's Next.js API routes or PostgreSQL integration; use a Node.js application host for a full server deployment.
