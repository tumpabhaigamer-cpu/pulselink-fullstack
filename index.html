PulseLink is a link-in-bio platform project built around an editable creator studio, flexible content blocks, service templates, and a phone preview beside the controls.

✦
What this public link is: a project overview and source-code hub. The Next.js app and API source are in the repository. They need a Node.js host, database, and configured provider credentials to run as a full service. This GitHub Pages page does not execute server routes.

What’s in the project

Built to serve creators and local businesses, with editing controls and visitor experiences in one system.

▦

Modular creator studio

Profile and link editing, content blocks, templates, layout controls, and a live device preview.

◈

Expressive page styles

Windowed Easy OS and Neon Motion concepts, color and image controls, animated cards, and video-first layouts.

⌂

Service-business flows

Gym, cafe, hotel, freelancer, and agency examples with inquiry, booking, menu, gallery, and project-scope cards.

▶

Media and embeds

Video, music, gallery, social, document, and link blocks for a richer visitor page.

▤

Full-stack foundations

Next.js app routes, PostgreSQL schema, Drizzle configuration, link management, and event endpoints are included in source.

◎

Growth integrations

Instagram and YouTube integration code, audience tools, analytics structures, and API configuration points.
